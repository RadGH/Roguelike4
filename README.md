# Roguelike 4 (working title)

A couch co-op, wave-based arena roguelite for 1–4 players — bright, whimsical, and
absolutely crawling with unlockables. Built with React + TypeScript + PixiJS; ships
as a static site (game + full manual) on GitHub Pages.

> The game's display title lives in `data/branding.json` and `src/game/branding.ts`
> only — it is a working title and will change.

## Status

Pre-production: design docs complete, engine scaffold next. See
[docs/design/](docs/design/README.md) for the full game design.

## Development

Docs for how the project is structured live in `docs/dev/` (created with the
scaffold). Player-facing docs live on the website (`/guide`).
